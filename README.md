# Ionic Tabs Starter

An Ionic/Angular tabbed application scaffold for local experimentation.

## Scope

The repository provides starter application structure. A distinct product workflow, backend service and deployed release are not established.

## Technology / Material

Ionic 8 · Angular 18 · Capacitor 6 · TypeScript

## Repository guide

- [package.json](package.json)
- [src/app](src/app)

## Getting started / Reproducibility

From the repository root, install a Node.js version compatible with the manifest, run `npm install`, then `npm start`.
